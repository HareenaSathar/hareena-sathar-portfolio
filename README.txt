Hareena Sathar - portfolio website
==================================
Static site: open index.html in a browser, or upload this whole folder (index.html + img/) to any static host.

Free hosting options
- GitHub Pages: create a repo named <username>.github.io, upload the contents of this folder, and the site is live at https://<username>.github.io
- Netlify Drop: drag this folder onto https://app.netlify.com/drop

To edit text, open index.html in any text editor. Images are in img/.
